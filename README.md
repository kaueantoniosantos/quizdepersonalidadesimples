# 🕹️ Quiz de Personalidade Simples

## 📋 Sobre o Projeto

Este é um projeto simples de **Quiz de Personalidade** (como aqueles famosos do Facebook), construído inteiramente com tecnologias Front-end. O objetivo é demonstrar uma solução prática para mapear escolhas do usuário a um resultado final específico (Guerreiro, Mago ou Ladrão).

O cálculo do resultado é feito através de um **sistema de pontuação por categoria**, onde a opção mais votada é declarada vencedora.

---

## 🚀 Tecnologias Utilizadas

| Tecnologia | Função |
| :--- | :--- |
| **HTML5** | Estrutura básica e conteúdo do quiz (`index.html`). |
| **CSS3** | Estilização moderna, focada em transformar as alternativas em botões fáceis de clicar (Mobile-Friendly). |
| **JavaScript (ES6+)** | Lógica central do quiz, manipulação do DOM e cálculo do resultado final. |

---

## ✨ Funcionalidades

* **Mapeamento por Categoria:** Cada alternativa de resposta é associada a uma das categorias (Guerreiro, Mago, Ladrão).
* **Contagem de Frequência:** O resultado é determinado pela categoria com a maior frequência de escolhas.
* **Interface Intuitiva:** Uso de CSS para transformar *radio buttons* em botões de seleção grandes e responsivos.
* **Mensagem Final Personalizada:** O resultado exibe um título e uma descrição únicos para cada perfil.

## 🛠️ Instalação e Execução

Como este é um projeto puramente estático (sem necessidade de servidor), a execução é imediata:

1.  **Clone o Repositório:**
    ```bash
    git clone https://github.com/kaueantoniosantos/quizpersonalizado
    ```
2.  **Execute:**
    Basta abrir o arquivo **`index.html`** diretamente no seu navegador.

## 📄 Estrutura de Arquivos

A estrutura do projeto segue as boas práticas de separação de código:

```
.
├── index.html          # Estrutura e conteúdo principal do quiz
├── style.css           # Estilos e aparência
└── script.js           # Lógica do quiz e dados das perguntas
```
