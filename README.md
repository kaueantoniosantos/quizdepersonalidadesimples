# 🕹️ Quiz Personalizado: Descubra Seu Personagem

## 📋 Sobre o Projeto

Este é um projeto simples e divertido de quiz de personalidade, desenvolvido para demonstrar habilidades básicas em **Desenvolvimento Web Front-end** (HTML, CSS e JavaScript). 

O quiz utiliza um **sistema de pontuação por categoria** para analisar as escolhas do usuário e gerar uma resposta final customizada (Guerreiro, Mago ou Ladrão), simulando aqueles quizzes populares de redes sociais.

---

## 🚀 Tecnologias Utilizadas

| Tecnologia | Função |
| :--- | :--- |
| **HTML5** | Estrutura básica e conteúdo do quiz. |
| **CSS3** | Estilização moderna, responsividade e transformação das alternativas em botões visuais. |
| **JavaScript (ES6+)** | Lógica central do quiz, mapeamento das respostas para categorias e cálculo do resultado final. |

---

## ✨ Funcionalidades

* **Lógica de Mapeamento:** Cada alternativa de resposta é mapeada para uma categoria (`Guerreiro`, `Mago`, `Ladrão`).
* **Contagem de Frequência:** O resultado é determinado pela categoria com o maior número de escolhas.
* **Interface Amigável:** O CSS transforma os *radio buttons* em botões de seleção grandes e fáceis de usar.
* **Responsividade:** O layout se adapta bem a diferentes tamanhos de tela (mobile e desktop).

## 🛠️ Instalação e Execução

Como este é um projeto puramente *front-end* e estático, a execução é simples:

1.  **Clone o Repositório:**

2.  **Execute:**
    Basta abrir o arquivo **`index.html`** diretamente no seu navegador.
